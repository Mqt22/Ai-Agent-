# Ai-Agent
How it works:
The Trigger (When chat message received): The process starts when you type a message to the bot.

The Brain (AI Agent): The central hub that decides how to answer you. It has three special "powers" attached to it:

Groq Chat Model (The Intelligence): This is the engine that generates the human-like text responses.

Simple Memory (The Context): This allows the bot to "remember" what you said 2 minutes ago so you can have a natural back-and-forth conversation.

Google Sheets (The Knowledge): This is the Tool. If you ask a question like "What is the status of my order?", the AI Agent uses this tool to "read" your Google Sheet and find the specific answer.

The "Big Picture"
In the first workflow, the AI was a secretary (taking notes and filing them).
In this workflow, the AI is a customer support agent (searching your records to answer your questions).
